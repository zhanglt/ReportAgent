## 2. 数据逻辑（与 database.md 规范对应）

### 2.1 降水量表 ST_PPTN_R

- `TM` 为**时段截止时间**，`DRP` 为 `(TM-1h, TM]` 的时段雨量，精度 0.1mm，无雨为 0；
- `INTV = 1.00`（HH.NN 格式，NN 为分钟，即 1 小时）；
- `PDR` 为实际降雨历时 HH.NN（如 `0.48` = 48 分钟），无雨为 0，恒 ≤ INTV；
- `DYP` 为**前一日 08:00 至当日 08:00** 共 24 个时段累计，**仅在每日 08:00 且资料完整时填写**
  （2025-01-01 08:00 因缺前一日资料为 NULL，其余 08:00 均与 24 时段之和一致）；
- `WTH`：5 雪 / 6 雨夹雪 / 7 雨 / 8 阴 / 9 晴；有雨必为降水码；
  高海拔站（阿坝、甘孜及 z0≥2500m）冬季（11~3 月）降水以雪/雨夹雪为主；
- `GGMD = '0'`（自动观测）。
- 雨量过程：月雨日概率 + 逐日 storm-cell 模型，按年标定到各市州目标年雨量
  （盆地 900~1700mm，雅安最多；川西高原 650~700mm；攀西干热河谷 850~1000mm）。

### 2.2 河道水情表 ST_RIVER_R

- 降雨 → 双线性水库汇流（快/慢两个线性水库，参数按大/中/小河流分级）→ 流量 `Q`；
- 水位由**水位流量关系曲线** `Z = Zref + (Q/a)^(1/b)`（b=2.0）反推，Z-Q 严格一致；
- `XSA = Q / XSAVV`（断面过水面积），`XSMXV ≈ 1.22 × XSAVV`（最大点流速 > 断面平均）；
- `WPTN` 由相邻时刻水位差判定：4 落 / 5 涨 / 6 平（阈值 ±0.005m）；
- `FLWCHRCD`：洪水起涨标记 `5`（流量向上穿越前 24h 均值 1.5 倍）、洪峰标记 `6`
  （超启动预报流量且为 ±6h 局部最大）；
- `MSQMT='1'`（水位流量关系曲线推流）、`MSAMT='1'`（水位面积关系曲线）、`MSVMT='9'`（其它）。

### 2.3 防洪指标表 ST_RVFCCH_B（阈值全部由同一关系曲线导出）

- 水位次序：`LAZ < SFZ < WRZ < TAZ < GRZ < LDKEL < RDKEL`
  （低水告警 < 启动预报 < 警戒 < 高水告警 < 保证 < 左堤顶 < 右堤顶）；
- 流量次序：`LAQ < SFQ < WRQ < TAQ < GRQ`，且 `FLPQ（平滩）< WRQ`；
- `SFQ = 0.85×WRQ`（启动预报低于警戒），`TAQ = (WRQ+GRQ)/2`（告警介于警戒与保证之间）；
- **实测最高/最低水位、实测最大/最小流量、历史最大断面平均流速及其出现时间，
  均取自生成小时序列的真实极值**（出现时间在 2025~2026 范围内）；
- 调查最高水位/最大流量略高于实测值，出现时间同场洪水；
- 历史最大含沙量 3~12 kg/m³，出现时间与实测最大流量一致；
- 序列限幅保证最高水位低于左堤顶 0.25m（不漫堤）。

### 2.4 预警指标表 ST_HIWRCH_B（每站 4 行）

| HIWRTY | HIWRCH | 蓝 | 黄 | 橙 | 红 |
| :-: | :-: | --- | --- | --- | --- |
| 0 洪水 | 0 水位 | SFZ | WRZ | TAZ | GRZ |
| 0 洪水 | 1 流量 | SFQ | WRQ | TAQ | GRQ |
| 1 干旱 | 0 水位 | z(0.60Q0) | z(0.50Q0) | LAZ | z(0.35Q0) |
| 1 干旱 | 1 流量 | 0.60Q0 | 0.50Q0 | LAQ | 0.35Q0 |

`WRSTAATR='00'`（瞬时值）。干旱阈值随严重度递减。

### 2.5 预报成果表 ST_FORECAST_F

- 每日 08:00 发布（`IYMDH`），依据时间 07:00（`FYMDH`），方案代码 `SC-DEMO-01`，
  预报单位「四川省水文水资源勘测中心」；
- 预报发生时间（`YMDH`）为 +6h（14:00）、+12h（20:00）、+24h（次日 08:00）；
- 预报值 = 对应时刻真实值 + 小误差（误差随预见期增大）；
- 发生时间超出 2026-12-31 23:00 的记录不生成（末日仅 2 条）。

### 2.6 内置暴雨洪水事件（保证超警戒/超保证测试场景）

| 时间 | 影响范围 | 强度放大 |
| --- | --- | --- |
| 2025-07-12 ~ 13 | 全省盆地及攀西 | ×3.2 |
| 2025-08-19 ~ 20 | 广元、南充、广安、达州、巴中（渠江/嘉陵江流域） | ×3.8 |
| 2026-06-20 | 攀枝花、凉山 | ×3.0 |
| 2026-07-17 ~ 18 | 全省盆地及攀西 | ×3.5 |
| 2026-08-09 ~ 10 | 成都、德阳、绵阳、雅安、乐山、眉山（岷江/沱江上游） | ×4.2 |

中小河流洪峰可达基准流量 7~10 倍（部分超保证水位），大江大河 2~4 倍（部分超警戒水位）。

### 2.7 字典与静态表

- `ST_TABLE_D`：9 张表的表编号/中英文名/交换标志（表编号取自 database.md；
  `ST_HIWRCH_B` 在 database.md 中未给出编号，置 NULL）；
- `ST_FIELD_D`：118 个字段的序号、中文名、类型、空值属性（N/空）、单位、取值范围、
  枚举标志、主键序号，与 schema.json 实际结构一致；
- 静态表 `MODITIME` 统一为数据集快照时间 **2026-12-31 23:00:00**；
- 测站 `ESSTYM/BGFRYM='202501'`，`USFL='1'`，基面「1985国家高程基准」。

## 4. 重新生成

```bash
# WSL CentOS9-stream，reportagent 环境
/opt/anaconda3/envs/reportagent/bin/python /opt/ReportAgent/scripts/generate_sichuan_dataset.py \
    --seed 20250101 --truncate
```

- 不加 `--truncate` 时，若任一目标表非空则直接退出（防误覆盖）；
- 脚本末尾自动执行 21 项一致性校验（行数、24 条/天、时间范围、DYP 累计、
  PDR≤INTV、天气码、Z-Q-面积-流速关系、阈值次序、外键完整性、超警戒统计等），
  结果写入 `dataset/sichuan_dataset_summary.json`；
- 刷新 NL2SQL schema 缓存：`cd /opt/ReportAgent && python -m NL2SQL.get_schema_cache`。

1. 查询成都市 2025 年 7 月 13 日每小时的河道水位和流量。

7. 查询每个市州警戒水位最高的测站及其保证水位。

## 6. 已知近似（测试数据声明）

- 站址坐标、集水面积、至河口距离、河流大小为**模拟近似值**，不代表真实测站；
- 水位基面为统一假定（Zref = 常水位 - 2.0m），防洪阈值由关系曲线导出而非真实核定值；
- 所有数据均为合成数据，仅用于 NL2SQL/报表功能测试。
